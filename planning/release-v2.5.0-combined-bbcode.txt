[b]Habitat v2.5.0[/b]

[b]New unit: Visadhara (spreadsheet)[/b]
[list]
[*]8 osc additive bass/lead/drum voice taking after a certain popular digital Eurorack module
[*]Phase-modulation matrix voice, 8 voices on a NEON 4-lane bus, 2x oversampling on the inner DSP loop
[*]Per-voice asymmetric pitch envelope, decoherent phase reset on trigger, golden-ratio phase offsets (avoids correlated-detune cancellation patterns)
[*]Dedicated post-fold envelope; pre-fold soft cap (loud and clean simultaneously)
[*]7 plies: V/Oct (with Bass/Alto/Tenor octave-register sub), f0 (coarse/fine), trig, Mode (Spread/Harm/Morph subs), fold, level, expanded
[*]Animated viz: vertical-standing K-gons on a carousel, per-pixel trigger shockwave bands, Fold contour field with photographic inversion when Fold>1, radial-wave interference field, Harmonic radius + Morph star overlays
[/list]

[b]New unit: Network (spreadsheet)[/b]
[list]
[*]Multi-tap comb / glitch reverb of original design. Useful as a shallow/lush spatializer, chaotic resonator, or microsound/shoegaze generator
[*]Set space very low, conn and decay very high for metallic overtone structures. Add glitch to stutter and crush. Drop density to hear glitch more clearly. Push size and density up for lush spaces. Conn is feedback. Motn alleviates runaway feedback and adds movement
[*]7 plies: glitch (gltch ply character macro), size, density, motion, connectivity, decay, wet
[*]Headline UI: gltch ply with G1-G8 mutually-exclusive character modes - G1 S&H, G2 multi-block stutter (motion-driven reseed, triangular distributions, zero-crossing loop boundaries, NEON 4-wide playback), G3 mute, G4 transient events, G5 scrub, G6 reverse, G7 tap respawn (drift), G8 bitcrush/decimate (with sub-modes)
[*]Equal-share CRUSH/SCRUB/REVERSE/NORMAL at glitch=1
[*]Listener-relative stereo pan, cap of 16 active stutter taps
[*]Viz: listener-centered Fibonacci sphere with per-tap trails, sonar + reflector flash, motion-driven Fibonacci perturbation, tilted 3D ping rings with reverse counter-rotation
[*]Optimized some but still heavy, fair warning
[/list]

[b]Hardware stability + Plaits 6op polish[/b]
[list]
[*]Plaits / Clouds engine / mode switching deterministically fixed on hardware (was an occasional hard-fault on engine swap). Root cause: GCC -O3 -ftree-vectorize -ffast-math emitting NEON :64/:128 alignment hints that trap on Cortex-A8 when alignment inference goes wrong. Fix: -fno-tree-vectorize appended last in CFLAGS for am335x across every package, plus link-time NEON-hint lint via tools/check-neon-hints.sh
[*]Belt-and-suspenders mi_barrier_noop() AAPCS spill barrier at audio-thread state-swap points
[*]Plaits 6-op FM (engines 5/6/7) now runs 2x oversampled. Less upper-octave aliasing on FM patches with mild treble rolloff from the gentle MA filter. Still cooking on this, it remains quite noisy
[/list]

[b]Optimization pass (secondary)[/b]
None change audio character; all free CPU budget at the same fidelity.
[list]
[*]Filterbank (was Tomograph): full NEON SoA SVF bank, drops stereo CPU to about 8% at 16 bands
[*]Petrichor: NEON SoA SVF kernel + multi-tap weighted feedback (true delay character) + default buffer 20s -> 5s
[*]Impasto + Parfait: NEON SoA refactor + fast paths
[*]Helicase: polynomial sin/tanh saves about 5% CPU on lofi mode; carrier shape parity fix
[*]Rings modal kernel (mi): about 10-15% inner-loop speedup
[/list]
